# AI-Powered Threat Dashboard

This project is a lightweight Flask application designed to monitor request traffic and detect anomalies using Z-score statistical analysis.

## Features
- **Backend**: Python Flask framework
- **AI/ML Module**: Z-Score based statistical anomaly detection engine
- **Frontend**: Responsive HTML/CSS/JS interface
- **Mobile Deployment**: Optimized for execution in Termux

## How to Run
1. Install dependencies: `pip install flask numpy`
2. Start the server: `python app.py`
3. Access in browser at `http://localhost:5000`
